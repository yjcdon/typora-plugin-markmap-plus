# Markmap Plus v2.0.1

- 悬浮按钮默认使用思维导图 SVG 图标。
- 导出目录通过系统文件夹选择器设置，路径只读显示，与选择按钮横向对齐。
- 默认导出到下载目录；选择目录后点击“保存修改”生效，取消选择保留原目录。
- 简化导出目录设置，移除路径输入说明和“使用默认目录”按钮。

更新时按 INSTALL.md 替换插件程序并保留 data 目录。已有自定义图标和导出目录设置继续保留；未设置导出目录时，已保存和未保存文档均使用下载目录。

已通过 TypeScript 检查、生产构建和选择器契约校验。macOS 27.2 / arm64 / Typora 1.12.3 已完成本地安装与用户试用确认；Windows 文件夹选择器待实机验收。

# Markmap Plus 2.0.0：独立 Typora 思维导图插件

2.0.0 将 Markmap Plus 改为独立交付。解压 `plugin.zip` 后，将 `markmap-plus` 文件夹交给 AI，按其中的 `INSTALL.md` 完成放置和启动入口配置，重启 Typora 即可使用。

## 本版内容

- 独立加载器和设置面板，支持旧版设置迁移、程序更新、入口恢复、停用与完整卸载。
- 标题、段落和嵌套列表导图，点击节点定位正文，实时编辑刷新并保留可匹配折叠状态。
- 浮窗拖动、调整尺寸、左右固定、缩放与适应视图；GitHub / Night 主题同步。
- HTML、SVG、PNG 三类导出，修复公式与本地图片展示；HTML 携带离线运行资源。
- 精简导出面板：三个格式按钮横向排列，点击外部或按 Esc 关闭，支持键盘焦点和方向键。
- 完善观察器、计时器、拖动监听和异步任务的释放，修复设置刷新后的固定布局与文档同步。

## 安装与升级

下载本页附件 **plugin.zip**，解压后让具备本地文件操作能力的 AI 阅读并执行 `INSTALL.md`。

1.x 使用社区框架的插件目录；2.0.0 使用独立 `markmap-plus` 目录和专属启动入口。升级时按说明迁移旧设置，并停用旧 Markmap 实例。更新独立版时保留 `data` 目录。

## 已验证环境

- macOS 27.2 / Apple Silicon arm64 / Typora 1.12.3。
- 实测覆盖独立启动、设置读写、多窗口、正文定位、编辑更新、三类导出、更新恢复与卸载。
- 宿主页隔离外网请求时，本地图片、公式和三类导出通过；大文档操作后 CPU 和驻留内存回落，组件重复释放检查通过。

Windows 10 平台适配保留，实机验收列为后续任务；其他宿主版本按实际组合验证。

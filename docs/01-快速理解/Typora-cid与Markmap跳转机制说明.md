# Typora cid 与 Markmap 跳转机制

Markmap 负责生成导图。插件负责将导图节点关联到 Typora 正文标题，并在点击时滚动定位。

## 标题映射

1. 编辑器适配器使用 Typora 大纲的 `getHeaderMatrix(true)`，按文档顺序采集标题的纯文本、层级和块 ID（`cid`）。加粗、链接、行内代码和实体字符由 Typora 解析，不能把 Markdown 原文直接与导图纯文本比较。
2. Markmap 初始化数据时为每个节点生成 `state.path`，路径包含祖先层级。
3. 插件遍历整棵树，仅将 `payload.tag` 为 `h1` 至 `h6` 的真实标题节点参与匹配，包括根标题。
4. 标题按出现顺序、层级和纯文本匹配，建立 `state.path -> cid` 映射。同名标题按先后顺序绑定到不同块，正文节点不消耗标题引用。
5. 内容签名包含 Markdown 和标题的 ID、纯文本、层级。切换到正文相同但块 ID 不同的文档时仍会重建映射。
6. 每次更新数据后立即重建映射，避免新节点使用上一次的标题映射。

多个一级标题产生的虚拟根没有标题标签，不建立正文映射。

## 点击行为

- 点击标题文字：通过当前路径查找标题 ID。
- 点击正文或列表文字：从当前路径向上查找最近的标题路径，定位到所属标题。
- 点击圆点：仅折叠或展开节点。
- 点击虚拟根，或没有所属标题的正文节点：不触发正文跳转。

Markmap 的节点数据没有 `parent` 引用。祖先查找使用 `state.path` 的层级前缀，不依赖不存在的属性。

定位链路为：

```text
节点文字点击 -> state.path -> 最近标题路径 -> cid -> 当前正文 DOM -> scrollIntoView
```

编辑器适配器在点击时通过 `#write [cid="..."]` 查询当前标题元素，立即滚动到标题并显示短暂的静态高亮。

## 相关代码

- `src/main.ts`：Typora 标题采集、按 cid 查询当前 DOM、正文滚动。
- `src/components/TocMindmap.ts`：标题映射、节点点击委托、最近祖先标题查找。

## 验证

验证完整的节点文字点击链路，覆盖根标题、标题间穿插列表、正文与深层列表、带格式的同名标题、不同层级的同名标题、多一级标题的虚拟根、正文相同但标题 ID 变化、内容更新后的映射，以及圆点不触发正文跳转。预期目标从样例源行和 Typora 标题顺序独立计算，不使用被测映射作为预期值。

# Typora cid 与 Markmap 跳转机制

Markmap 负责生成导图。插件负责将导图节点关联到 Typora 正文标题，并在点击时滚动定位。

## 标题映射

1. 编辑器适配器使用 Typora 大纲的 `getHeaderMatrix(true)`，按文档顺序采集标题的纯文本、层级和块 ID（`cid`）。加粗、链接、行内代码和实体字符由 Typora 解析，不能把 Markdown 原文直接与导图纯文本比较。
2. Markmap 初始化数据时为每个节点生成 `state.path`，路径包含祖先层级。
3. 插件遍历整棵树，仅将 `payload.tag` 为 `h1` 至 `h6` 的真实标题节点参与匹配，包括根标题。
4. 标题按出现顺序、层级和纯文本匹配，建立 `state.path -> cid` 映射。同名标题按先后顺序绑定到不同块，正文节点不消耗标题引用。
5. 内容签名包含 Markdown 和标题的 ID、纯文本、层级。切换到正文相同但块 ID 不同的文档时仍会重建映射。
6. 每次更新数据后立即重建映射，避免新节点使用上一次的标题映射。

## 正文块映射

编辑器适配器按正文顺序采集标题及段落自身的 `cid` 和纯文本。列表项使用其内部段落的 ID，不把子列表文字拼入父项。

插件为每个可定位节点建立 `state.path -> cid` 映射。标题和正文分别匹配，正文只在当前标题范围内按出现顺序匹配，区分同名列表项。内容签名同时包含正文块的 ID，避免编辑后沿用旧 ID。

多个一级标题产生的虚拟根没有标题标签，不建立正文映射。

## 点击行为

- 点击标题文字：通过当前路径查找标题 ID。
- 点击正文或列表文字：定位并高亮这一项自身的正文块。
- 点击圆点：仅折叠或展开节点。
- 点击虚拟根或未绑定正文块的节点：不触发跳转，不回退到其他标题。

Markmap 的节点数据没有 `parent` 引用。点击直接使用当前节点的块映射，不查找父标题。

定位链路为：

```text
节点文字点击 -> state.path -> 当前节点的 cid -> 当前正文 DOM -> scrollIntoView
```

编辑器适配器在点击时通过 `#write [cid="..."]` 查询当前正文块，立即滚动并显示短暂的静态高亮。默认滚动偏移为 0，让点击的那一项对齐编辑区顶部；用户可在设置中调整偏移。

## 相关代码

- `src/main.ts`：Typora 标题及正文块采集、按 cid 查询当前 DOM、正文滚动。
- `src/components/TocMindmap.ts`：标题与正文块映射、节点点击委托。

## 验证

验证完整的节点文字点击链路，覆盖标题、正文与深层列表、同名标题和列表项、编辑后块 ID 更新，以及圆点不触发正文跳转。预期目标从正文 DOM 中每一项自身的文本和 ID 独立获取，不把父标题当作正文项的预期目标。

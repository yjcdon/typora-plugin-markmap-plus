2. 补齐宿主大文档基线与持续操作；小样例宿主资源趋势、组件计数和组件大文档测量沿用已有记录。
3. 验证真实 Typora 升级后的页面与宿主能力，入口重建机制沿用 E-24。
4. 在 Windows 10 实机逐项执行适用用例，填写实际系统、架构与 Typora 版本。
5. 以最终结果更新 manifest 兼容记录、任务完成状态与发布包说明。

## 4. Review 修复与复验范围

- 设置面板：异步读取结束时校验会话 generation，关闭后的回调保持界面已释放状态。类型检查通过。
- 配置存储：写入成功后发布变更，失败保留原快照；同窗口排队提交，取消订阅和 destroy 清理回调。E-06、E-07 已覆盖。
- 本地资源与导出：构建内嵌 KaTeX 样式和字体，导出接入内嵌资源；PNG 首段和公式、独立 HTML 的公式与交互已验证。本地图片改为原生 SVG image，重新导出的 PNG 实图确认正常。
- 生命周期：Observer、防抖、计时器、渲染异步结果和拖拽释放已纳入实现；WebKit 组件重复释放与合成大文档已有 E-09～E-11，宿主内运行趋势继续按 TC-19 验证。

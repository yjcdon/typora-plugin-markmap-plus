## 执行约束与记录

复用现有 TypeScript 与构建工具；代码修改遵循仓库规范，按涉及文件执行现有静态检查和生产构建。测试用例采用人工步骤与记录；新增测试类按用户明确要求安排。

安装实测涉及本机 Typora 文件修改，应在保存文档、退出应用及具备操作授权后进行。备份、替换、恢复均记录实际路径；清理文件采用废纸篓操作。

实现采用主代理与子代理协作，已按功能提交平台能力、设置面板、生命周期与独立启动。后续修复和验收继续按任务更新。代码检查、模拟、WebKit 运行和 Typora computer-use 分别记录；Windows 的模拟结果只用于分支逻辑验证。
